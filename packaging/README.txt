PlateUp! - تعريب كامل للعبة
PlateUp! - Arabic translation
================================================================

ما هذا / What this is
----------------------------------------------------------------
تعريب كامل للعبة PlateUp! يُركَّب كإضافة (mod). لا يُعدَّل أي ملف
من ملفات اللعبة: حذف مجلد الإضافة يعيد اللعبة كما كانت تمامًا.

A complete Arabic translation of PlateUp!, delivered as a mod.
No game file is modified - deleting the mod folder puts the game
back exactly as it was.


التركيب على ويندوز / Installing on Windows
----------------------------------------------------------------
انقر نقرًا مزدوجًا على install-windows.bat
سيبحث المثبّت عن اللعبة وحده. إن لم يجدها اضغط "استعراض..."
وحدّد المجلد الذي يحتوي على PlateUp.exe

Double-click install-windows.bat
It finds the game by itself. If it cannot, click Browse and pick
the folder that has PlateUp.exe in it.

إن ظهرت رسالة عن الصلاحيات، شغّل الملف بزر الفأرة الأيمن ثم
"تشغيل كمسؤول".
If it reports a permissions problem, right-click the file and
choose Run as administrator.


التركيب على لينكس / Installing on Linux
----------------------------------------------------------------
    ./install.sh

ولتحديد مسار اللعبة يدويًا / to give the path yourself:

    ./install.sh /path/to/PlateUp


تشغيل التعريب / Turning it on
----------------------------------------------------------------
شغّل اللعبة، افتح الإعدادات، واختر "العربية" من قائمة اللغات.

Start the game, open Settings, and choose العربية in the
language list.


الإزالة / Removing it
----------------------------------------------------------------
ويندوز: شغّل install-windows.bat واضغط "إزالة".
لينكس:  ./install.sh --uninstall

Windows: run install-windows.bat and click إزالة (Uninstall).
Linux:   ./install.sh --uninstall


ملاحظة / Note
----------------------------------------------------------------
الجولات المُعدَّلة لا تُسجَّل في قوائم السرعة (speedrun
leaderboards). الإنجازات واللعب الجماعي لا يتأثران.

Modded runs are not eligible for the speedrun leaderboards.
Achievements and multiplayer are unaffected.
