PlateUp! — التعريب العربي / Arabic translation
================================================================

ما هذا / What this is
----------------------------------------------------------------
تعريب كامل لـ PlateUp! على هيئة إضافة (mod): القوائم والأطباق
والبطاقات والأجهزة والوصفات والإنجازات. لا يُعدَّل أي ملف من ملفات
اللعبة: كل شيء في Mods/PlateUpArabic، وحذفه يعيد اللعبة كما كانت.

A complete Arabic translation of PlateUp!, delivered as a mod. No
game file is modified - everything lives in Mods/PlateUpArabic and
deleting it puts the game back as it was.


المتطلبات / Requirements
----------------------------------------------------------------
ويندوز 10 أو 11، أو أي توزيعة لينكس حديثة. لا يلزم تثبيت أي برنامج.
Windows 10/11 or any modern Linux. Nothing else to install.


التثبيت على ويندوز / Installing on Windows
----------------------------------------------------------------
1. أغلق اللعبة.
2. انقر نقرًا مزدوجًا على install-windows.bat.
3. اضغط "تثبيت". سيبحث المثبّت عن اللعبة وحده؛ إن لم يجدها اضغط
   "استعراض..." وحدّد المجلد الذي يحتوي على PlateUp.exe.
وإن ظهرت رسالة عن الصلاحيات، شغّل الملف بزر الفأرة الأيمن ثم
"تشغيل كمسؤول".

1. Close the game.
2. Double-click install-windows.bat.
3. Press Install. It finds the game by itself; if it cannot, press
   Browse and pick the folder that has PlateUp.exe in it.
If it reports a permissions problem, right-click the file and
choose Run as administrator.


التثبيت على لينكس / Installing on Linux
----------------------------------------------------------------
    ./install.sh

ولتحديد مسار اللعبة يدويًا / to give the path yourself:

    ./install.sh /path/to/PlateUp

وإن ظهرت Permission denied، فمدير الملفات لم يحفظ صلاحية التنفيذ:
    chmod +x install.sh && ./install.sh


تشغيل التعريب / Turning it on
----------------------------------------------------------------
شغّل اللعبة، افتح الإعدادات، واختر "العربية" من قائمة اللغات.

Start the game, open Settings, and choose العربية in the
language list.


الإزالة / Removing it
----------------------------------------------------------------
ويندوز: شغّل install-windows.bat واضغط "إزالة".
لينكس:  ./install.sh --uninstall

Windows: run install-windows.bat and click إزالة (Uninstall).
Linux:   ./install.sh --uninstall


النسخة المدعومة / Supported version
----------------------------------------------------------------
اللعبة 1.5.2. إن حُدِّثت اللعبة وبدا نص في غير موضعه، أعد تثبيت أحدث
إصدار من التعريب.

Game 1.5.2. If the game updates and something looks off, install the
newest release of the translation over it.


ملاحظة / Note
----------------------------------------------------------------
الجولات المُعدَّلة لا تُسجَّل في قوائم السرعة (speedrun
leaderboards). الإنجازات واللعب الجماعي لا يتأثران.

Modded runs are not eligible for the speedrun leaderboards.
Achievements and multiplayer are unaffected.
